# Contributing

This repository contains **proprietary software** owned by Ashish Naulach
(see [`LICENSE`](./LICENSE)). It is published for reference and deployment by
the owner, not as an open-source project.

## External contributions are not accepted

Pull requests, forks intended for redistribution, and derivative works are not
accepted and will not be merged. No license is granted to copy, modify, or
distribute the original source code except with the owner's explicit written
permission.

## Reporting a security issue

Please **do not** open a public issue for anything security-sensitive. Follow
the process in [`SECURITY.md`](./SECURITY.md) and contact the owner privately via
the GitHub account <https://github.com/Ashishnaresh>.

Never include real credentials, tokens, private URLs, or personal/user data in
an issue, discussion, or pull request.

## Authorized-use reminder

This platform generates application-layer HTTP load. It must only be used
against infrastructure that the operator owns or is explicitly authorized in
writing to test.
